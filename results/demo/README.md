# Demo screenshots

Generated by `e2e/flow/flow.spec.ts` during `make e2e`. The flow drives the real
control service and the local gateway mock on a fixed clock
(2026-11-02, Europe/Berlin), signs in to the console as Priya, and makes the
member calls through the mock's HTTP routes with each member's gateway key.

recorded in step 3. Prompts and responses are never stored; the mock charges a
fixed USD 0.30 per call and keeps ids, models, tokens and cost only.
