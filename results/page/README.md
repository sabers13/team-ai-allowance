# Project page data

`page-data.json` is generated by `make page` from the committed evidence files
and is the single source for the numbers on
`dist/team-ai-allowance/index.html`.

Sources:

- `results/live.json` — the live CLI check;
- `results/dogfood.json` and `results/dogfood-probes.json` — the team test;
- `results/demo/flow.json` — the request-flow demo steps;
- `results/sim/*.json` — the weekend simulation, labelled `simulation` in each file.

`src/report/page-data.ts` refuses to build when a source file is missing or a
literal fact is no longer present in its source. Derived counts (for example
`3` verified CLIs and `18/18` live steps) are computed from the parsed arrays in
the same files. The page itself is rendered by `web/build.ts` from this data and
`web/page.css`; there are no hand-typed figures in the HTML template.

Rebuild:

```sh
make page
```

The generated page and its local screenshots live in
`dist/team-ai-allowance/`.
