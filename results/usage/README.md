# Usage-page evidence

Generated by `e2e/console/console.spec.ts` with `TAA_SHOT_DIR=results/usage` on
the console fixture server (localhost only, no real model calls). The same page
is mounted by `taa serve` and appears as `results/demo/step-10-usage.png` in the
scripted demo.

| Shot | What it shows |
| ---- | ------------- |
| `usage-360-light.png`, `usage-360-dark.png` | Phone: period tabs, custom-date form, summary, stacked chart, member cards. |
| `usage-1280-light.png`, `usage-1280-dark.png` | Desktop: the same page at 1280, light and dark. |
| `usage-model-1280-light.png` | The chart stacked by model instead of member. |
| `usage-custom-1280-light.png` | A custom `from`/`to` range applied. |

Tests in the same run cover:

- keyboard-reachable sort links and `aria-sort`;
- the custom-date form round trip in the URL;
- `/usage.csv` as `text/csv` with `content-disposition: attachment` and the
  same rows, order and columns as the table;
- axe with zero serious or critical issues at 360 and 1280, light and dark;
- no horizontal scroll of the page at either width.

This folder is the screenshot source for the usage-page evidence, alongside `results/demo/`.
